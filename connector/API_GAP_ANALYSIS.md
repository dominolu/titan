# Connector API 差距说明

本文件原先保存了一份逐端点快照，但它与实现同步更新困难，曾和覆盖清单对同一接口给出
相反结论。为避免两个事实来源继续漂移，接口实现状态现统一维护在
[API_COVERAGE.md](API_COVERAGE.md)。

覆盖清单中的状态含义：

- ✅：已实现，并有解析测试、请求构建测试或明确记录的实连验证；
- ⚠️：代码和离线测试已完成，但仍缺少当前版本的端到端实连验证；
- 🔧：底层客户端具备能力，但尚未接入连接器或策略主路径；
- ❌：尚未实现。

新增或修改交易所接口时，只更新 `API_COVERAGE.md`，并在对应实现附近增加测试。网络或
真实账户验证必须保持为 `#[ignore]`，避免 CI 发送外部请求或订单。
