# 订单流微观结构指标体系（完整规范）

版本 v1.0 · 2026-11-14 · 适用：加密永续与现货；输入为逐笔成交、订单簿增量流、强平流和 OI 等低频数据

## 0. 使用说明

每个指标给出：定义、公式、输入数据、用法、失效条件。角色标记：**\[A\]** alpha 触发，**\[S\]** 状态调节，**\[G\]** 风控闸门，**\[F\]** 信号过滤。标注「待验证」的解读是假设，必须按第 9 节检验后才能进入策略。不同角色的指标不能同层加权相加：慢信号调节快信号的参数，闸门拥有最高优先级。

## 1. 数据与通用约定

| 数据         | 内容                         | 频率             |
| ------------ | ---------------------------- | ---------------- |
| T 逐笔成交   | 时间戳、价格、数量、主动方向 | 事件             |
| B 订单簿增量 | depth diff 重建多档深度      | 事件             |
| L 强平流     | 强平方向、价格、数量         | 事件（可能节流） |
| O 低频数据   | OI、资金费率、基差、期权     | 秒到分钟         |

- 时间戳：一律用交易所时间戳排序，不用本地接收时间。
- 方向：taker 买为 +1，taker 卖为 -1。币安 aggTrade 的 isBuyerMaker=true 表示主动卖；其他交易所逐个确认字段语义。
- 单位：多所、多合约聚合前统一成币数或名义价值，币本位张数与 U 本位币数不可直接相加。
- 标准化：z-score 用滚动中位数/分位数，窗口按成交量时钟或同时段样本，避免被昼夜成交量差异扭曲。
- 增量：所有指标 O(1) 更新，单一 BookState 状态机，一次解析、多处共用。
- 缺失：断线、丢包时标记 invalid，重连后重置累计量基准，不带着偏差继续累加。

## 2. 核心指标

### 2.1 Delta \[A/S\]

窗口内主动买入量减主动卖出量。

```
delta      = Σ buy_qty − Σ sell_qty
delta_norm = delta / volume          # 取值 −1 到 1，跨标的、跨时段可比
```

窗口取多尺度：100ms、1s、10s、1min。用法：与 OFI 同向互相确认；delta\_norm 比绝对值更稳。失效：刷量平台会污染 delta，需限制单平台权重；无方向数据时用 Lee-Ready 或 tick rule，精度明显下降。

### 2.2 CVD \[S/A\]

```
CVD_t = CVD_{t-1} + delta_t
```

CVD 的绝对值没有意义，取决于起点；有信息的是变化量、斜率以及与价格的关系。改造版本：

| 版本     | 公式                              | 用途                                  |
| -------- | --------------------------------- | ------------------------------------- |
| 滚动 CVD | 最近 T 内 delta 之和              | 去除起点漂移，即 trade flow imbalance |
| 衰减 CVD | S ← S · 2^(−v/v\_half) + delta | 成交量时钟，无重置断崖                |
| 锚定 CVD | 从重大事件点起累计                | 观察一段行情内的买卖压力              |

价格与 CVD 组合的常见读法（待验证）：价涨 CVD 升为主动买推动；价涨 CVD 不升为被动单撑起或空头回补；价跌 CVD 升为主动卖被承接。现货与永续必须分开计算，两者背离本身有信息。

### 2.3 大订单 \[A/F\]

**(a) 成交大单。** 阈值取滚动分位数与中位数倍数的较大者：

```
q_big = max( P99(近 N 笔 qty), k · median(qty) )
big_net   = Σ big_buy − Σ big_sell
big_ratio = big_volume / volume
```

**(b) 父单聚合。** 同方向、间隔小于 Δt（如 200ms）、价差不超过 m 个 tick 的连续成交合并为一个父单，输出总量、持续时间、平均间隔、尺寸方差。固定尺寸加固定间隔暗示算法拆单执行（VWAP/TWAP 切片），后续往往还有同向成交（待验证）。

**(c) 挂单大单（墙）。** 条件：量大于该档位近期 90 分位。可信度打分：

```
credibility = w1·log(寿命) + w2·(1 − 历史撤单率) + w3·被成交确认比例
```

新挂不久、曾反复撤单的墙降权。墙被吃到剩余不足初始量的 20%–30%，且同侧下方 2–5 档深度在近 500ms 内净减少，触发 depletion 信号（见 3.4）。失效：假单诱导、冰山单补单，墙被补回则立即放弃。

### 2.4 爆仓 / 强平 \[A/G\]

数据来自交易所强平流；部分交易所对强平推送做了节流，数据可能不完整，需用 OI 骤降与成交异常交叉验证。方向：多头被强平为卖单，空头被强平为买单。

```
liq_long  = Σ 多头被强平量（窗口）
liq_short = Σ 空头被强平量
liq_net   = liq_short − liq_long          # 大于 0：空头被挤，买压
liq_ratio = (liq_long + liq_short) / volume
```

**级联判定：** 强平总量与 liq\_ratio 均超过各自 99 分位，且价格同向位移超过 k·ATR。

**清算簇估算：** 用 OI 增量按入场价分配，对常见杠杆（5/10/20/50/100x）近似估算清算价 entry·(1 ∓ 1/lev)，忽略维持保证金，汇成价位直方图。

```
cluster_dist = (price − 最近大簇价位) / ATR
cluster_size = 簇内估算名义价值 / 日均成交额
```

用法：临近大簇时收紧仓位和报价（闸门）；簇被扫穿后，强平量见顶回落、delta 反转、吸收分数升高，组合起来是潜在衰竭反转的特征（待验证）。链上永续 DEX 可直接读取账户清算价，优先于估算。失效：杠杆分布未知、用户追加保证金导致估算偏差。

### 2.5 吸收 \[A/F\]

定义：主动流很大但价格几乎不动，说明对手方被动单在承接。

```
impact = |ΔP| / ATR_win
absorb = z(|delta_norm|) − z(impact)
方向：delta > 0 且 absorb 高 → 买被吸收，上方有被动卖
      delta < 0 且 absorb 高 → 卖被吸收，下方有被动买
```

Kyle's λ 是更严格的量化：滚动回归 ΔP\_k = λ · delta\_k + ε，λ 相对自身分位骤降即吸收。

**订单簿确认**（降低误判）：该侧一档补单率高；该价位累计成交量大而可见深度几乎不降；冰山分高；吸收期间对侧撤单少。

吸收持续而 delta 衰竭，价格反向移动的概率上升（待验证）。价格穿过吸收价位且 delta 同向继续，视为吸收失败，是止损依据。失效：低流动性时段 delta 本身很小，z 分数不稳；波动突变时 ATR 滞后。

## 3. 订单簿类指标

### 3.1 Imbalance 与 Microprice \[A\]

```
imb       = (Qb − Qa) / (Qb + Qa)                 # 一档；多档用距离衰减权重
microprice = (Pb · Qa + Pa · Qb) / (Qa + Qb)
```

多档加权时限制单档贡献上限，防止一张大单决定整个信号。

### 3.2 OFI \[A\]

相邻两次报价快照的差分，统一挂单、撤单、成交（Cont-Kukanov-Stoikov）：

```
e_bid = Qb         若 Pb > Pb_prev
      = Qb − Qb_prev 若 Pb = Pb_prev
      = −Qb_prev   若 Pb < Pb_prev
e_ask = −Qa_prev   若 Pa > Pa_prev
      = Qa − Qa_prev 若 Pa = Pa_prev
      = Qa         若 Pa < Pa_prev
OFI = e_bid − e_ask
```

多档 OFI 对各档求和后加权，预测力通常高于一档；配 EWMA（100ms、1s、5s）。OFI 含挂撤信息，delta 只含已发生成交，两者分歧本身是特征。

### 3.3 点差与深度状态 \[S/G\]

点差单边拉宽、±10bp 深度骤降，常对应做市商调整库存或躲避毒性流。深度恢复速度（resilience）：被吃掉一块流动性后补回所需时间，越慢越脆弱，同时是做市风险指标。

### 3.4 Depletion 与撤单比 \[A/F\]

托单被吃到低位时，真正推动价格冲刺的是后排撤单形成的流动性真空，不是继续吃单。

```
cancel_rate  = 同侧 N 档撤单量 / 同侧挂单量（滚动）
otr          = 订单数 / 成交数（价位级）
触发：墙剩余 < 20–30% 且 cancel_rate 抬升且主动成交方向一致
否决：该价位量回补、对侧突然堆量、低流动性时段
```

### 3.5 订单寿命与冰山 \[F\]

订单寿命分布：专业做市商和 penny-jump 机器人寿命极短，定时刷新的散户机器人呈固定周期。冰山分：同价位反复被吃又反复出现，或成交量远超可见量。两者用于对挂单型信号降权。

## 4. 成交结构类指标

| 指标         | 定义                                                                                                        | 角色 |
| ------------ | ----------------------------------------------------------------------------------------------------------- | ---- |
| 尺寸分布     | 大单、中单、小单占比；小额密集倾向散户，少量大额倾向机构或算法，同样的 delta 来源不同表现可能不同（待验证） | S    |
| 同向连续长度 | 同方向主动成交连续出现的笔数和量，反映单一大单拆分还是多方博弈                                              | A    |
| 扫单         | 一次主动单穿过的档数与频率，多档同时成交即 sweep                                                            | A    |
| Hawkes 强度  | 成交自激发，量化跟风持续程度                                                                                | A/S  |
| 跳跃占比     | bipower variation 分离连续波动与跳跃，跳跃占比高时滑点和信号衰减不同                                        | S    |
| VPIN         | 成交量桶内买卖不平衡，衡量对做市商的毒性                                                                    | G    |

```
Hawkes：λ ← λ · exp(−β·Δt) + α        # 每笔成交增量更新，买卖分开计算
VPIN  = Σ_{n 个桶} |V_buy − V_sell| / (n · V_bucket)
```

VPIN 不是 alpha，是闸门：超阈值时收窄报价、缩小 size 或停机。

## 5. 衍生品指标（加密特有）

**OI 与价格、delta 的组合 \[A/S\]**（区分新开仓与平仓）：

| 价格 | OI | 解读                   |
| ---- | -- | ---------------------- |
| 涨   | 升 | 新多头推动             |
| 涨   | 降 | 空头回补，缺乏新增买盘 |
| 跌   | 升 | 新空头推动             |
| 跌   | 降 | 多头平仓               |

**资金费率 \[S\]：** 极端值表示单边拥挤，预测资金费率比已结算值更及时；结算时点前后有机械性挂撤和平仓，单独做时段分析。

**基差 \[S\]：** 永续或季度合约对现货的溢价，反映杠杆需求。

**现货与永续背离 \[A/S\]：** `z(CVD_perp) − z(CVD_spot)`；永续主导的上涨常是杠杆推动，现货主导的更持续（待验证）。

**期权 \[S\]：** gamma 暴露与隐含波动率，大到期日附近对现货波动有机械性放大或抑制，频率低，不适合秒级。

## 6. 成本与价位类指标

**成交量衰减成本线 \[S\]：** 取代每日重置 VWAP，按成交量衰减。

```
decay = 0.5 ^ (v / v_half)
S_pv  = S_pv·decay + p·v ;  S_v = S_v·decay + v ;  S_ppv = S_ppv·decay + p²·v
cost  = S_pv / S_v ;  σ = sqrt(max(S_ppv/S_v − cost², 0))
偏离度 = (price − cost) / σ
```

v\_half 取日均成交量（用滚动中位数估计，避免前视）的 2%、10%、50% 三档，用排列与间距表示短、中、日级成本状态；单笔 v 截尾到 99.9% 分位；现货与永续分开算。

**Volume Profile \[S\]：** POC 是成交量最大的价位，VAH/VAL 是包含约 70% 成交量的区间上下沿，LVN 附近价格易快速穿越。窗口内用 developing POC，只用截至当时的数据，用完整窗口回头标注是前视偏差。POC 是众数，成本线是均值，两者距离 `(cost − POC)/σ` 可作为特征。永续上可用 ΔOI>0 的部分加权，更接近新开仓成本。

**锚定 VWAP \[S\]：** 锚在重大摆动高低点、强平瀑布起点、周开盘，代表某一批参与者的平均成本；与衰减成本线互补。

**FVG / OB 客观化 \[S\]：** 三根 K 线的 FVG 是几何关系，加密 24h 连续交易下它依赖 K 线周期。用订单流定义：FVG 区间内逐笔成交量是否确为低量节点；OB 区间位移前是否有大量被动吸收、CVD 背离。区域与 LVN、大额挂单位置的重合度是可验证特征。

## 7. 状态特征

| 特征                                                   | 作用                           |
| ------------------------------------------------------ | ------------------------------ |
| 时段（亚欧美、美股开盘、整点、资金费率结算前后、周末） | 同一信号在不同时段预测力差别大 |
| 成交量分位（相对同时段）                               | 判断放量缩量，不用绝对值       |
| 流动性（±10bp 深度、点差成本）                        | 低流动性时滑点吃掉 edge        |
| 波动率 regime（分位数分类）                            | 信号有效性随波动状态变化       |
| 行情延迟                                               | 超阈值自动撤单停报价           |

## 8. 组合规则

**分层：** \[A\] 触发交易，\[S\] 调节参数和阈值，\[F\] 对信号降权或否决，\[G\] 优先级最高，触发时第一动作是撤单，再考虑平仓。同一现象的不同指标（delta、TFI、扫单频率、同向连续长度）高度共线，聚类后每簇留一两个代表。

**典型情景（均为待验证假设）：**

| 情景     | 特征组合                                                            |
| -------- | ------------------------------------------------------------------- |
| 趋势延续 | delta 同向、OFI 同向、OI 升、吸收分低、突破时墙被撤                 |
| 衰竭反转 | 强平量见顶回落、delta 反转、吸收分高、OI 降、价格接近成本线偏离极值 |
| 假突破   | 突破价位处 delta 弱、吸收分高、OI 未增、价格迅速回到价值区          |
| 毒性风险 | VPIN 高、点差单边拉宽、深度恢复慢、临近清算簇                       |

**仲裁：** 同标的所有意图先 netting；优先级为取消 > 反向 > 同向加仓；被动单与主动单不同时存在于同一价位附近；全局设总敞口与单位时间成交额上限，相关性在尾部会趋近 1，按压力情景定风险预算。

## 9. 验证规范

1. **无成本 IC 先行**：每个指标对未来 100ms、1s、10s、1min 收益计算 IC，先筛掉无效项。
2. **分桶**：按时段、波动率分位、成交量分位、距上次大波动时间分桶，看稳定性。
3. **对照组**：随机信号、随机水平位（与价格距离分布相同）作对照，只看相对对照组的差值。
4. **增量检验**：对已有特征回归取残差，新特征对残差的 IC 才算增量；或固定模型加入前后比较样本外 IC。
5. **前视偏差**：developing POC、滚动分位数、日均成交量估计均只用当时可得数据。
6. **成本与延迟**：预测视界要大于执行延迟和手续费对应的价格位移；回测必须模拟队列位置、taker 费率、真实滑点；用 mid 成交的回测视为无效。
7. **稳健性**：跨标的、跨时间段、对窗口与分桶参数不敏感；每个自由度都要有理由。
8. **影子模式**：上线前只计算不下单，对比真实成交的 markout。

## 10. 实现要点

- 单一 BookState，增量更新，FeatureBus 统一发布；快通道单线程，慢通道异步写原子变量。
- Numba 实现用预分配数组或 jitclass 保存状态，不在 njit 函数里创建 Python 对象；与原版 Python 实现逐 tick 平行比对，重点测首个 tick、锁价穿价、单边缺失、桶边界。
- 每个指标输出带有效标志（warm-up 未满、数据缺失时为 invalid），下游不得使用无效值。
- 所有阈值和窗口集中配置，随回测版本一起记录。
