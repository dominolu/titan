# 仓库隐私与验证记录

公开仓库保存代码、可复现方法和经过脱敏的验证结论。真实环境地址、SSH 身份、凭据、账户快照、订单与成交明细、原始日志及含隐私的附件保存在私有档案中。

公开文档使用 `titan-build`、`titan-live`、`account-service.internal` 和 `/workspace` 作为占位。实际环境由运维人员在 Git 之外保存；编译和非实盘验证仍只能在指定编译服务器执行，实盘操作仍服从 AGENTS.md 的授权与风险约束。需要主机身份校验的脚本读取私有环境变量 `TITAN_BUILD_ADDRESS`，未设置时拒绝执行；不能将该变量用于自行更换授权服务器。

2026-11-01 完成公开历史脱敏。原始验证文件及其摘要和签名保存在私有备份中，公开摘要不是未经修改的原始验收证据。历史报告中的源码与产物摘要标识原始私有快照，不证明脱敏后的文件字节或后续修改已经通过验证。需要审计原始记录时通过项目维护者获取受控访问。

公开验证目录仅接受 Markdown 摘要。原始 JSON、日志、命令输出、截图和文档附件应写入 Git 之外的受控目录；仓库中的 `internal-docs/` 与 `.secrets/` 已忽略。忽略规则不能阻止强制添加，也不能清理历史，提交与推送检查必须同时启用。

新克隆执行 `git config core.hooksPath .githooks`，安装提交前和推送前的隐私内容检查。检查只输出文件、行号和类别，不回显命中值；CI 使用同一内容检查。项目构建、代码静态检查和测试继续在指定编译服务器执行。

历史重写后，应备份未提交工作并重新克隆，或由维护者按提交映射迁移；禁止合并或推回清理前的历史。旧备份只能保存在私有位置，不得推送到公开远端。

检查覆盖受跟踪文本、可达历史、作者邮箱及 DOCX XML。截图、音视频和其他二进制附件仍需人工检查；公开合约地址与许可证中的上游署名应保留，不能用批量删除取代人工判断。
