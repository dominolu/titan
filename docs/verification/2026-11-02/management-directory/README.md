# 账户管理与策略入口更新

日期：2026-11-02。验证与构建在 `titan-build` 的独立源码快照中完成；本地仅编辑、审查与浏览页面。预览部署沿用已有隔离快照，并替换本轮 20 个明确列出的管理端、前端及配置说明文件；没有把本地其他未提交修改纳入该部署。输入清单、文件摘要、原始日志、数据库备份与截图保存在版本控制之外的私有档案。

## 变更

- “账户风险”改为“账户管理”，提供账户资料新增、编辑、资料停用与凭据引用，保留原风险/账户事实视图。目录资料不激活连接器，不授予实际账户交易权限。
- 策略管理拆为“实盘策略”“策略回测”，共享策略身份、参数与版本。原策略详情 URL 保留兼容。
- 构建节点可显式开启单文件 Python 源码登记。上传内容不可变保存，重试复用同一源码登记；实际校验和编译仍通过原 Operation/worker 执行。

## 部署范围

配套校验前端预期程序摘要与实际程序摘要一致后，备份管理数据库并切换非实盘预览的管理器和构建节点。登录配置保持原样。部署后通过 API 和页面新增 3 个明确标注为示例的模拟账户，以及网格、配对套利、双均线 3 个策略源码记录。账户资料、源码与操作回执保存在服务端。

本轮没有真实账户连接、交易所下撤单、实盘策略启动或实际历史回测收益验收。页面存在实盘入口不代表当前预览具备真实账户授权。截图和原始证据没有收入公开仓库；本摘要只保留方法、结果、数量及覆盖限制。
