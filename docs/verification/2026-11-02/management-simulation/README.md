# 回测与实盘页面的模拟示例

日期：2026-11-02。承接[账户与策略目录更新](../management-directory/README.md)，本轮仅修改前端，在 `titan-build` 的独立目录完成检查和构建。已验证的后端程序、构建节点、账户目录和登录配置保持原样；前端预览更新为 revision-03。

## 展示范围

- 网格、配对套利、双均线分别提供 3 组模拟回测，共 9 组，包含有利、不利和风险终止情形，以及权益曲线、收益、回撤、费用与成交概览。
- 3 组模拟运行分别展示运行中、暂停、停止，包含示例账户、持仓、挂单、敞口、延迟和告警。
- 只对指定策略 ID 且名称明确带“（示例）”的记录启用默认模拟视图。页面持续标注虚构数据、只读用途，并保留“真实记录”切换。
- 数值和状态来自独立的前端合成 fixture，不登记为引擎结果、账户事实、部署或实际运行。模拟视图没有提交交易、回测或生命周期操作的入口。
