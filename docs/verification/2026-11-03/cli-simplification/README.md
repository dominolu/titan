## 已验证行为

1. `titan serve [manager|node] --config ...` 运行后台角色；`titan_cli` 提供 strategy/account/research/config 二级树。旧 console、本机 Registry、恢复及存储维护入口保留兼容，日常命令不自动猜测本机作用域。
2. 根、分组、叶子和全局参数 help 均可离线查看。仅 TTY 无参进入 shell，非 TTY 无参显示帮助；机器模式无动作返回版本化输入错误，不读取重定向输入、不隐式认证。
3. 可读名称在授权范围内唯一解析；准确 ID/alias 固定目标，歧义拒绝，不自动选择最新版本或运行。默认等待，detach 仅受理；中断不取消远端任务。
4. 私有 journal 先持久化意图与原键，再发起写入。同输入的进行中/未知任务只读找回，显式 journal 不创建新意图。迟到的控制终态可被新的普通命令明确重试，研究中间成功阶段继续原流水线。明确拒绝还须成功核对原键无已受理任务才关闭，网络错误或单独空查询不构成未受理证明。
5. 4 个并发客户端只自动启动 1 个明确配置的本机 manager，不启动 node 或策略。已有监听服务也校验数据库路径/origin 的不透明身份摘要；不匹配不重启、不降级。已有启动记录但管理库缺失时拒绝重建空库，恢复原备份后字节一致。
6. 数据库向导、参数方式、show/check 均可离线操作；仅保存秘密引用。SQLite 默认，PostgreSQL 仅历史投影；管理和执行恢复仍本地 SQLite。已有配置与固定存储身份不原位覆盖，未迁移或未验证的配置显示候选；不声称仅修改客户端配置就修改了远端节点。
7. PostgreSQL 检查有总期限，固定 target ID 不匹配拒绝；PEM 只接受有界普通文件，FIFO、目录、缺失、超大或错误内容拒绝。回测新阶段的资源 revision/digest 与最终冻结 NodeRequest 同一快照核验，避免准备/提交阶段间数据漂移。
8. 默认人读输出有界并过滤终端控制符，金融值保留原值与缺失语义；JSON/NDJSON 保持版本化机器信封。历史、上下文和阶段记录放用户私有 state，退出 shell 不停止策略或后台服务。

## 范围与证据

本轮是 Linux 编译服务器上的合成账户、回环 API、真实原生工具链、历史输入与临时 PostgreSQL 验收。未连接真实交易所账户，未开展实盘交易、生产数据迁移、浏览器部署、全部 in-flight 取消竞态或独立 SSE 重连专项扩验；不声明交易所历史完整性。原有报告的已验证范围不被本报告重写。

PostgreSQL 专项使用回环明文隔离容器，不扩大为生产 TLS 或所有 PostgreSQL 部署的验收。数据库配置需要切换已有数据时仍走原 prepare/校验/activate 流程，候选状态不会被伪装成生效。既有 immutable profile、恢复库与业务归属边界不变。

公开材料只保留固定用例名称、方法、计数、代码/程序摘要及限制。原始命令、配置、数据库、请求、日志、PTY transcript、签名材料、输入清单、校验和清理结果保存在 Git 外的私有档案，本文不复制其私有字段。
